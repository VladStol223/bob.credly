1

Install the badging extension

Step 1: Copy the download prompt below and paste it directly into your Bob chat. Bob will download the bob-badge-ext-0.0.6.vsix extension file straight into your workspace.

COPY & PASTE THIS PROMPT INTO BOB 
Please download the file at https://vladstol223.github.io/techweek.bob/bob-badge-ext-0.0.6.vsix and save it as bob-badge-ext-0.0.6.vsix in the current workspace directory. Once the file is saved, confirm it is present and tell me you are ready for the next step.

Once Bob responds and confirms the bob-badge-ext-0.0.6.vsix file is saved in your workspace, advance to Step 2.

STEP 2 OF 6
2

Install the extension in Bob

Once Bob has saved the file, install it from the Extensions panel:

  1. Open the Extensions panel — the puzzle-piece icon in the left sidebar
  2. Click ⋯ More Actions in the top-right of the panel
  3. Select Install from VSIX…
  4. Choose bob-badge-ext-0.0.6.vsix from your workspace folder
  5. Bob will reload — the badging skill is now installed
