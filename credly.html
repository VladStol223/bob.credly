How to claim your

Credly Badge

  1. Install the VS Code badging extension
  2. Activate it with the event API key
  3. Switch to Badge Auditor mode in Bob
  4. Run the audit prompt for your track
  5. Credly sends your badge by email

STEP 1 OF 6
1

Install the badging extension

Copy the prompt below and paste it into Bob. It will download the bob-badge-ext-0.0.6.vsix file into your workspace folder.

Prompt to paste into Bob
Please download the file at https://vladstol223.github.io/techweek.bob/bob-badge-ext-0.0.6.vsix and save it as bob-badge-ext-0.0.6.vsix in the current workspace directory. Once the file is saved, confirm it is present and tell me you are ready for the next step.

Once Bob confirms the file is saved, move on to Step 2.

STEP 2 OF 6
2

Install the extension in Bob

Once Bob has saved the file, install it from the Extensions panel:

  1. Open the Extensions panel — the puzzle-piece icon in the left sidebar
  2. Click ⋯ More Actions in the top-right of the panel
  3. Select Install from VSIX…
  4. Choose bob-badge-ext-0.0.6.vsix from your workspace folder
  5. Bob will reload — the badging skill is now installed
WALKTHROUGH
Install from VSIX
STEP 3 OF 6
3

Activate the extension & enter your API key

After Bob reloads, click the IBM Bob Badge Issuer icon in the left sidebar.

  1. Press Enter when Bob prompts you
  2. Type in the API key shown on the screen at the front of the room
The API key is shown on the presentation screen in your room — you don't need to write it down in advance.

4–5

Switch mode & open a fresh chat

STEP 4 · SWITCH MODE

Use the mode picker at the bottom-left of the chat panel to switch Bob into Bob Badge Auditor mode.

How to switch modes in Bob
STEP 5 · NEW CHAT

Before pasting the audit prompt, start a fresh chat in Bob.

  1. Click the ✕ in the top-right of the chat panel — next to the blue bobcoin spend button
A clean chat keeps prior conversation from confusing the auditor, so your badge evaluation stays accurate.
STEP 6 OF 6
6

Start the badge audit

You're in Badge Auditor mode in a fresh chat. Copy your track's audit prompt and paste it into Bob.

The prompt contains all the completion criteria Bob needs to evaluate your work and guide you through the Credly claim process.

What happens next: Bob reviews your session, confirms you completed the track criteria, and starts the Credly badge issuance. Watch your email — the claim link arrives within a few minutes.
Your Credly badge is one prompt away.
The audit prompt for your track is on the main event page.
