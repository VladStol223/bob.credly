1

Download Badging Extension

Copy and paste this prompt directly into your Bob chat. Bob will download bob-badge-ext-0.0.6.vsix straight into your workspace folder.

PROMPT TO PASTE INTO BOB 
Please download the file at https://vladstol223.github.io/techweek.bob/bob-badge-ext-0.0.6.vsix and save it as bob-badge-ext-0.0.6.vsix in the current workspace directory. Once the file is saved, confirm it is present and tell me you are ready for the next step.

Once Bob confirms the file is downloaded, advance to reveal Step 2.

2

Install from VSIX

Install the downloaded extension package from VS Code Extensions panel:

  1. Open the Extensions panel (puzzle icon on left)
  2. Click ⋯ (More Actions) at top right
  3. Select Install from VSIX…
  4. Select bob-badge-ext-0.0.6.vsix & let Bob reload

PAGE 3 OF 3 · STEPS 5–6
5

Open a Fresh Chat

Before running the badging audit prompt, start a clean chat session:

  1. Click the ✕ (New Chat) icon in the top-right corner of the chat panel.
  2. Confirm you are in a blank conversation with Bob Badge Auditor selected.
Starting fresh clears out token clutter so your badging evaluation and prompt work seamlessly.
6

Run Badge Audit Prompt

Copy the Bobathon badging prompt below and paste it into your fresh chat:

BOBATHON BADGING PROMPT 
You are the Bob Badge Auditor for this Bobathon event.

Your objective:
1. Check the workspace directories and project files to inspect and summarize the participant's progress and work.
2. Regardless of specific track milestones or partial completion, because the user is participating in this live Bobathon event, they have fully earned their Credly badge.
3. Prompt the user for their full name and email address to issue their Credly badge, and execute the badge issuance tool.
All Bobathon attendees earn the badge! Check your email for the Credly claim link within minutes.
